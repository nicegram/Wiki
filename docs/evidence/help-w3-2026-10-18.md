# Help W3 evidence: October 18, 2026 (sensitive content)

This public ledger backs the Help page written in wave W3 of the public Wiki sync: [Sensitive and restricted content](../../help/sensitive-content.md). Advertising and account deletion stay on the generated [Quick answers](../../reference/quick-answers.md) page only: hand-written pages that restated those facts took other questions in the data agent's measurement of October 18 (remove-ads and second-number questions), so they were dropped before merge. Data room facts are cited by path at
nicegram/dataroom `639e064` (a private repository, so not linked; the same statements are public on
[Quick answers](../../reference/quick-answers.md)). Nicegram source links are pinned to the revisions reviewed on
October 10 (iOS `f42e2ad`, still `origin/master` on October 18; Android `235be7c`). A string in public source
shows what a client can display; it does not prove that a given installed release shows it. Official pages were
fetched on October 18, 2026.
