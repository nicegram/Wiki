# Help W10 evidence: October 23, 2026 (search button in the tab bar)

This public ledger backs the section [Where is the search button (magnifying glass)?](../../features/profiles-and-folders.md#where-is-the-search-button-magnifying-glass),
written for users who asked on October 20 why a magnifying glass suddenly appeared. Nicegram iOS source links are
pinned to release commits: 2.4.0 `7219b83`, 2.4.1 (build 628) `17a6d9a`, 2.6.3 (build 721) `f42e2ad`, 2.6.4
(build 725) `f75b666` and the 2.6.5 beta `7725236`; each version is read from `versions.json` at that commit.
Telegram's upstream source is pinned to `fb0e62b`. The App Store version was read from Apple's lookup API on
October 23, 2026. Source shows what a build can display; it does not prove what a given device shows.
