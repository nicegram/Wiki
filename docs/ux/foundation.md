# Nicegram public-help UX foundation

## Users

1. **Everyday messenger** — wants a familiar Telegram-compatible client with a few
   practical additions and minimal setup.
2. **Multi-account professional** — separates personal, client, channel, and work
   identities and needs fast switching and repeatable replies.
3. **Privacy-conscious user** — wants selected chats or accounts away from the
   normal app surface and needs clear recovery expectations.
4. **Cross-language communicator** — translates messages, transcribes audio, and
   uses AI assistance when available.
5. **Advanced user** — uses AI, beta tools, or source builds and accepts
   that availability can depend on platform, plan, region, or rollout.

## Jobs to be done

- Install the correct official build without guessing which link is current.
- Sign in with an existing Telegram account and understand who provides messaging.
- Add, switch, hide, back up, or restore accounts safely.
- Communicate faster with templates, translation, transcription, and media tools.
- Understand which features are Nicegram additions and which come from Telegram.
- Discover why a documented feature is missing without assuming the app is broken.
- Make an informed decision before sending content to AI or recording a call.

## Content principles

- Lead with the user outcome.
- Put availability before instructions when it can block the task.
- Use the exact product name and current domain.
- Never turn code presence into a release claim.
- Link to policy for legal meaning; summarize only what a user needs for the task.
- Give recovery steps next to irreversible or easy-to-misunderstand actions.
