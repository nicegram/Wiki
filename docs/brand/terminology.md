# Nicegram terminology

| Use | Avoid | Reason |
|---|---|---|
| Nicegram | NiceGram, Nice Gram | Product spelling |
| independent Telegram client | official Telegram client | Nicegram is not affiliated with Telegram |
| Telegram account | Nicegram account, when referring to chat login | Authentication is through Telegram |
| account switcher | profile carousel, unless that is the visible UI label | Clear user action |
| Double Bottom | double bottom mode, hidden mode | Feature name |
| hidden chats / hidden accounts | secret account | Avoid confusion with Telegram Secret Chats |
| quick replies | canned messages | Current product name |
| video message / round video | circle video | Match common Telegram terminology |
| AI Assistant | Lily, only when the current UI uses that name | Prevent stale model/persona claims |
| available | live | User-facing clarity |
| beta | coming soon | Beta can already be available to some users |
| limited rollout | available to everyone | Honest distribution status |
| `nicegram.me` | the retired public domain | Current public domain |

Do not name private modules, internal services, feature flags, or backend routes in
public pages.
